# 7M Accessories Website

Official frontend website for 7M Accessories.

This project is a modern product showcase platform designed to display automotive accessories without traditional e-commerce functionality. Customers can browse products and make enquiries directly via WhatsApp or phone.

## 🚀 Tech Stack

- React.js
- JavaScript (ES6+)
- Vite
- Tailwind CSS
- HTML5
- CSS3

## ✨ Features

- Modern, premium UI design
- Product showcase grid (no pricing)
- WhatsApp enquiry integration
- Responsive design (mobile-first)
- Clean component-based architecture

## 📦 Project Purpose

This website focuses on:
- Brand presence
- Clean product display
- Direct customer communication
- Fast and lightweight performance

No cart. No checkout. Direct enquiry model.
